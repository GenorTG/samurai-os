- **`samurai adopt`** brings an older install to the current defaults, only when you ask: it shows a
  preview, takes a snapshot and runs one full pacman transaction. Software you removed stays removed.
  Run `sudo samurai update` first, then `sudo samurai adopt`.
  - It **applies the Samurai KDE system defaults** (`/etc/xdg`); settings in your home directory win.
  - It installs the security baseline and **adds the AppArmor kernel parameter** to the boot menu
    (shown in the preview). Your own `lsm=` parameter is kept. A snapshot rollback does not remove the
    parameter: `sudo samurai boot set param remove lsm`.
  - An existing Firefox `policies.json` of your own is kept; the Samurai one is saved as `.pacnew`.
- **Security baseline** on new installs: AppArmor, kernel and network hardening, sudo and core dump
  defaults, a Firefox policy (telemetry off, uBlock Origin). `samurai security status` reports each
  item; `samurai security tpm enroll` adds TPM2 unlock with a PIN (the passphrase keeps working).
- **`samurai firewall`**: zones, ports and one-step presets (KDE Connect, Steam, Sunshine, LocalSend and
  more). mDNS stays closed.
- **`samurai welcome`** opens once at the first desktop login; Plasma's Welcome Center no longer starts
  by itself.
- **`samurai hw`**: shows the driver profiles for your hardware, applies them with a snapshot first and
  reports hardware changes. No driver is installed unattended. NVIDIA behaviour was tested on simulated
  hardware only (see "Verified").
- Fixed: the update notifier reported "reboot pending" permanently, and did not run at all for an account
  without a Samurai cache directory.
- Not included: Secure Boot setup (nothing verifies the boot partition yet) and gpu-unlock.
